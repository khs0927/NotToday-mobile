# NotToday 개발 로드맵

## Phase 0 — 안전 기준선

목표: 위험하거나 실제 기능과 일치하지 않는 동작을 제거합니다.

- [x] 자동 119 SMS 제거
- [x] 고정 GPS 좌표 제거
- [x] 24시간 WakeLock 제거
- [x] Flutter ↔ Android 채널 연결
- [x] 센서 권한 요청
- [x] 충격 후 실제 저활동 검사
- [x] 최근 유효 심박 보조 확인
- [x] 안전 확인 UI와 다이얼러 동작 일치
- [x] 제품 범위를 안전 보조 프로토타입으로 수정

완료 조건: 코드 리뷰 가능한 Draft PR 생성.

## Phase 1 — 재현 가능한 Android 빌드

목표: 새로운 개발자가 저장소를 받아 Wear OS debug APK를 만들 수 있게 합니다.

- [x] Flutter Android scaffold 복구
- [x] Gradle 배포판과 wrapper properties 고정
- [x] compileSdk·targetSdk·minSdk 확정
- [x] JDK 17 기준 고정
- [x] Kotlin·AndroidX 의존성 확정
- [x] Android debug APK CI
- [x] APK 체크섬과 artifact 생성
- [x] 패키지명·SDK·Wear 기능·금지 권한 CI 검사
- [x] debug 키를 release signing에서 제거
- [x] 로컬 설치 절차 작성
- [ ] 표준 `gradlew` 스크립트와 wrapper JAR 저장소 포함 여부 확정
- [ ] 서로 다른 개발자 환경 3곳에서 로컬 빌드 성공
- [ ] Wear OS 실기기 설치 성공

CI 완료 조건은 달성했습니다.

```text
flutter pub get
flutter analyze
flutter build apk --debug
```

Phase 1 전체 완료 조건은 세 명의 서로 다른 환경과 최소 한 대의 Wear OS 실기기에서 성공하는 것입니다.

## Phase 2 — Health Services 전환

목표: Wear OS 장시간 수집을 지원하는 저전력 센서 계층을 구축합니다.

- [ ] Health Services 의존성 추가
- [ ] MeasureClient로 개발·디버그 측정
- [ ] PassiveMonitoringClient로 장시간 심박 수집
- [ ] Wear OS 6 건강 권한 대응
- [ ] 센서 지원 기능 런타임 검사
- [ ] 손목 미착용·신호 불량 상태 정의
- [ ] 배터리 기준 측정

완료 조건: 화면이 꺼진 8시간 시험에서 목표 배터리 소모 기준을 충족하고 데이터 누락률을 기록함.

## Phase 3 — 위험 상태 머신

목표: UI와 센서 코드에 흩어진 위험 상태를 하나의 결정론적 엔진으로 통합합니다.

- [ ] NORMAL / RECHECK / SAFETY_CHECK / DIALER_READY / RESOLVED
- [ ] 상태 전이 이벤트 모델
- [ ] 사용자 취소와 확인 처리
- [ ] Cooldown·중복 이벤트 억제
- [ ] 프로세스 재시작 복구
- [ ] Room 이벤트 저장소
- [ ] 단위 테스트와 속성 기반 테스트

완료 조건: 모든 상태 전이와 실패 경로가 자동 시험으로 재현됨.

## Phase 4 — 실기기 낙상 후보 검증

목표: 여러 기기와 활동에서 오탐·미탐을 계량합니다.

시험 범주:

- 걷기·달리기
- 계단
- 손뼉·문 열기
- 책상 충격
- 워치 낙하
- 앉기·눕기
- 통제된 매트 낙상
- 운동 중 급격한 팔 동작

산출물:

- 기기별 샘플링 특성
- 특징 분포
- 후보 발생률
- 오탐률
- 미탐률
- 임계값 버전

완료 조건: PM·QA·안전 담당이 승인한 시험 보고서가 존재함.
