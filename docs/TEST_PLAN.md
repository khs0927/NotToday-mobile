# NotToday MVP 시험 계획

## 1. 시험 목표

- 저장소에서 앱을 재현 가능하게 빌드할 수 있는지 확인합니다.
- 권한, 센서, 백그라운드 실행과 사용자 취소 경로를 검증합니다.
- 정상 활동과 워치 낙하에서 불필요한 안전 확인이 발생하지 않는지 확인합니다.
- 앱이 실제 수행하지 않은 신고·진단을 성공으로 표시하지 않는지 확인합니다.

## 2. 시험 환경 기록

각 시험 결과에 다음 정보를 남깁니다.

- 기기 제조사와 모델
- Wear OS 버전
- Android API 수준
- 앱 commit SHA
- 배터리 시작·종료 값
- 워치 착용 여부
- 휴대전화 연결 여부
- 네트워크 상태
- 권한 상태
- 시험 영상 또는 센서 로그 위치

## 11. 병합 게이트

다음 조건을 모두 만족해야 안전 기준선 PR을 `main`에 병합할 수 있습니다.

- 정적 검사 통과
- Android debug 빌드 성공
- 최소 한 대의 실제 Wear OS 기기 설치 성공
- 권한 허용·거부 시험 통과
- 자동 SMS와 자동 통화가 없음을 확인
- 워치 낙하 시험에서 안전 후보가 발생하지 않음
- 충격 후 움직임 시험에서 후보가 폐기됨
- UI 문구 검토 완료
- 알려진 제한사항이 README에 기록됨

실기기 시험 전에는 PR을 Draft로 유지합니다.
